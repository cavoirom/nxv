I recently learned a trick to make an indicator for external link from
[Mu-An's website](https://muan.co), it perfectly matches with my expectation
about the indicator. I was tempted to add the indicator in the past and quickly
found that there's no Unicode character (yet) for this purpose, using an image
is not my taste. So I hesitated to add it. Now, when you see a strange character
after the link, you know the link will go to another website and it will open in
a new tab.
