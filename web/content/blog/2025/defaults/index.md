From [going-flying.com](https://www.going-flying.com/blog/defaults.html) I
discovered an interesting topic on tracking the default app that I used for a
specific purpose. Let's see how it will look like as time goes by.

- Calendar: Apple Calendar.
- Cloud storage: iCloud.
- Code editor: IntelliJ, vim.
- Contacts: Apple Contacts with CardDAV.
- Mail client: Yahoo! Webmail, Apple Mail.
- Mail service: Yahoo!, Outlook.
- Messages: iMessages.
- Notes: Apple Notes.
- Password manager: KeePass.
- Photo editing: Capture One.
- Photo library: Apple Photos.
- RSS client: NetNewsWire.
- Screenshots: macOS built-in tool.
- Search: Kagi.
- Terminal: kitty.
- Web browser: Chrome, Firefox, Safari.
